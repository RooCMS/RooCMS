# Moderation

[Общие правила и оглавление](../../README.md). Реализация: [ModerateController](../controller_moderate.php).

Доступ: модератор (m/a/su). Нельзя модерировать себя и пользователя с равной или более высокой ролью. `user_id` — обязательный int в пути.

## POST /v1/moderate/ban/{user_id}

JSON: необязательные `until` (числовой Unix timestamp; отсутствие/null/0 — бессрочно, положительная дата не должна быть в прошлом) и `reason` (string, по умолчанию пустая строка; обрезаются пробелы).

Пример: `POST /api/v1/moderate/ban/12`, тело `{"until":0,"reason":"Нарушение правил"}`.

200: сообщение `User banned successfully`, без data.

Ошибки: 400 — неверная дата/тип причины; 401/403 — доступ или запрещённая цель; 404 — нет пользователя; 500 — блокировка не выполнена.

## GET /v1/moderate/unban/{user_id}

Снимает блокировку. Без тела. Текущая реализация меняет данные через GET.

Пример: `GET /api/v1/moderate/unban/12`.

200: сообщение `User unbanned successfully`, без data.

Ошибки: 401/403 — доступ или запрещённая цель; 404 — нет пользователя; 500 — снятие блокировки не выполнено.
